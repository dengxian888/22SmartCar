# M5-3 系统设计说明

## 1. 系统架构
系统分为 Host 侧（主机终端）和 Robot 侧（小车端）。
Host 侧包含 Flask Web 服务器，统一处理裁判指令、急停触发、热切请求及审计记录；Robot 侧仅新增一个极简的订阅者节点。

## 2. 多层安全急停设计
为确保绝对安全，急停分四个层级实现：
1. **指令层**：Web 终端向 `/cmd_vel` 发布 `Twist()` 零速指令。
2. **话题层**：向 `/emergency_stop` 发布 `"LOCK"` 信号。
3. **控制器层**：锁定参数服务器（预留接口）。
4. **记录层**：触发瞬间写入审计日志，不等待人工确认。
**防误触设计**：急停状态无自动恢复，必须通过显式复位接口（或重启）才能解除。

## 3. 热切换与回滚机制
- 通过 ROS2 的 `SetParameters` 服务完成。
- 切换前获取旧参数值。若服务返回失败或超时，自动使用旧值重新调用服务，完成回滚。
- 全程记录审计日志。
